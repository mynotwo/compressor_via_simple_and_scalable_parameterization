# Accelerating General-Purpose Lossless Compression via Simple and Scalable Parameterization

Yu Mao, Yufei Cui, Tei-Wei Kuo, and Chun Jason Xue · ACM Multimedia 2022.

[Read the paper (PDF)](https://mynotwo.github.io/assets/pdfs/accelerating-lossless.pdf)

The paper studies general-purpose lossless compression with a parameterized ordered mask for history-symbol importance and an MLP for feature learning.

## Repository contents

This repository currently contains this README and a license. Implementation code and reproduction scripts are not included.
